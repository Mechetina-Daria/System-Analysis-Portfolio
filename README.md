#Портфолио Системного Аналитика | Мечетина Дарья Евгеньевна

Я начинающий системный аналитик с опытом проектирования информационных систем, моделирования бизнес-процессов и проектирования баз данных. 

В этом репозитории собраны примеры моих артефактов, созданных в рамках стажировки и комплексных проектов.

## Мой стек технологий
* **Нотации:** BPMN, UML, EPC, DFD
* **Базы данных:** SQL, проектирование ER-моделей (DBML, 3НФ)
* **Архитектура:** Понимание клиент-серверной архитектуры и принципов интеграций ИС
* **Инструменты:** Draw.io, dbdiagram.io, Git, Python
