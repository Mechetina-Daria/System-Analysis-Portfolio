# Спецификация функциональных требований (FRS)
**Подсистема:** «Отчетность и аналитика» корпоративного портала  

Данный документ описывает состав реализуемых функций, порядок взаимодействия системы с пользователем и правила формирования аналитической отчетности.

---

## 1. Общие системные требования
1. **Интерфейс:** доступ к разделу осуществляется через корпоративный портал, разработанный на технологии **1С:Элемент**.
2. **Кроссплатформенность:** подсистема должна корректно работать через web-интерфейс на персональных компьютерах и мобильных устройствах.
3. **Интеграция:** получение данных (Backend) осуществляется посредством обращения к системе **1С:Документооборот (1С:ДО)**.
4. **Валидация запросов:** перед отправкой запроса в 1С:ДО подсистема обязана выполнять проверку корректности введенных пользователем параметров.
5. **Обработка ошибок:** при обнаружении некорректных параметров система должна блокировать отправку, уведомлять пользователя и предоставлять возможность исправления.
6. **Отображение:** после получения обработанных данных из 1С:ДО подсистема формирует и выводит итоговый отчет в интерфейсе портала.

---

## 2. Требования к аналитическим модулям

### 2.1. Модуль «Анализ загрузки сотрудников»
* **Цель:** формирование отчета по текущей загрузке персонала.
* **Доступные фильтры (настройка параметров):**
  * Исполнитель
  * Проект
  * Руководитель
  * Блок
  * Статус
  * План
* **Отображаемые данные в отчете:**
  * Проект, блок, статус, теги.
  * Плановые показатели: запланированное время, план.
  * Фактические показатели: остаток по задаче.
  * Сводка: количество активных проектов, количество задействованных специалистов.

### 2.2. Модуль «План-факт анализ и эффективность проектов»
* **Цель:** сопоставление плановых и фактических показателей проектной деятельности.
* **Доступные фильтры (настройка параметров):**
  * Проект / Проектная задача
  * Статус
  * Период
* **Отображаемые данные в отчете:**
  * Статус выполнения проекта.
  * Временные метрики: плановые и фактические показатели, длительность.
  * Ресурсные метрики: трудозатраты.
  * Итоговые показатели эффективности проекта.

### 2.3. Модуль «Анализ компетенций персонала»
* **Цель:** оценка профессионального уровня сотрудников.
* **Доступные фильтры (настройка параметров):**
  * Физическое лицо (сотрудник)
  * Специальность / роль
  * Навыки
* **Отображаемые данные в отчете:**
  * Сведения о сотруднике.
  * Категории компетенций.
  * Результаты: уровень оценки, баллы.
  * Ответственный за оценку.

### 2.4. Модуль «Анализ прохождения обучения»
* **Цель:** контроль статусов образовательных мероприятий сотрудников.
* **Доступные фильтры (настройка параметров):**
  * Сотрудник
  * Статус
  * Дата экзамена
  * Город
* **Отображаемые данные в отчете:**
  * Статус прохождения обучения и комментарий.
  * Данные экзамена: дата, номер попытки.
  * Финансовая информация: сумма, наличие/счет ERP.
  * Локация (город).

### 2.5. Модуль «Анализ сертификации сотрудников»
* **Цель:** учет и контроль сроков действия профессиональных сертификатов.
* **Доступные фильтры (настройка параметров):**
  * Физическое лицо
  * Статус сертификата
  * Тип сертификата
* **Отображаемые данные в отчете:**
  * Владелец сертификата.
  * Наименование и номер сертификата.
  * Временные рамки: дата получения, срок действия, признак бессрочности.
  * Системная информация: статус сертификата, дата загрузки.

---

## 3. Требования к UI/UX и экспорту данных

1. **Единый паттерн:** все аналитические отчеты должны использовать единый стандартизированный механизм настройки параметров (фильтрации) и формирования результатов.
2. **Бесшовность:** пользователь должен получать результаты анализа исключительно внутри корпоративного портала, без принудительного перехода (редиректа) в другие информационные системы.
3. **Адаптивность:** интерфейс дашбордов и таблиц должен автоматически подстраиваться под разрешение экрана устройства (ПК / Смартфон).
4. **Экспорт документов:** подсистема должна поддерживать функционал автоматического формирования готового документа для скачивания в следующих форматах:
   * Табличный формат (напр., Excel/CSV)
   * Текстовый формат (`.docx`, `.pdf`)
