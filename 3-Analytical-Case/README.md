# Сборник аналитических кейсов

⬅️ **[Вернуться на главную страницу портфолио](../README.md)**

В этом разделе собраны решения небольших продуктовых, архитектурных и бизнес-задач. 
В отличие от комплексных проектов, эти кейсы демонстрируют мои навыки решения точечных нестандартных проблем, сбора требований и применения различных нотаций моделирования (UML, BPMN) для конкретных бизнес-сценариев.

---

## Каталог кейсов в этом разделе:

### 1. [Проектирование системы безопасной печати](./secure_print.md)
* **Проблема:** утечка конфиденциальных документов с общих офисных принтеров.
* **Что сделано:** разработаны 3 варианта программного решения (без изменения аппаратной части). Проведен Trade-off анализ. Описан пошаговый алгоритм защиты через PIN-коды и виртуальную очередь.

### 2. [Проектирование ИТ-системы для телешоу «Мир загадок»](./tv_show_system.md)
* **Бизнес-задача:** описать логику проведения телеигры и спроектировать концепцию информационной системы для её поддержки (хранение, обработка заявок и отбор контента).
* **Что сделано:** спроектирована сквозная BPMN-модель процесса. Описаны алгоритмы работы системы (UML Activity, Use Case) и логическая ER-модель базы данных. Собраны нефункциональные требования для обеспечения отказоустойчивости в прямом эфире.
